# Exchange Monitor 产品需求文档 (PRD)

## 1. 产品目标

### 1.1 核心目标
构建一个交易所竞品监控可视化平台，通过 BTC 价格与交易量多曲线对比，结合动态事件标注，帮助运营团队快速洞察市场变化、竞品动态和业务机会。

### 1.2 业务目标
- **监控效率**：一屏看清主要交易所业务线数据变化
- **归因分析**：通过事件标注辅助解释量变原因
- **决策支持**：为运营策略调整提供数据依据

---

## 2. 目标用户

| 用户角色 | 使用场景 | 核心诉求 |
|----------|----------|----------|
| 运营团队 | 日常监控竞品交易量波动 | 快速发现问题 |
| 市场分析师 | 分析事件对交易量的影响 | 数据 + 事件关联 |
| 管理层 | 查看整体市场趋势 | 高层视图，关键指标 |
| 客服/Support | 解答用户关于市场活动的问题 | 事件时间线追溯 |

---

## 3. MVP 范围

### 3.1 核心功能 (MVP)

| 功能 | 描述 | 优先级 |
|------|------|--------|
| BTC 价格曲线 | 主图为 BTC/USDT 价格，走势时间为横轴 | P0 |
| 多交易所交易量叠加 | 支持 Binance、OKX、Bybit、Bitget、Hyperliquid | P0 |
| 业务线切换 | 切换查看：总量 / 现货 / 合约 | P0 |
| 交易所勾选 | 勾选启用/禁用特定交易所曲线 | P0 |
| 事件时间流 | 图表下方展示时间轴对应事件 | P0 |
| 事件分类筛选 | 支持按类型筛选事件（公告/活动/上币/产品更新/社媒/行业新闻） | P1 |
| 事件详情弹窗 | 点击事件展示摘要 | P1 |

### 3.2 数据范围 (MVP)

- **交易所**：Binance、OKX、Bybit、Bitget、Hyperliquid
- **业务线**：现货、合约
- **时间范围**：近 30 天数据
- **更新频率**：每小时更新

### 3.3 MVP 交付标准
- [ ] 页面可正常加载，显示 BTC 价格曲线
- [ ] 可叠加 5 家交易所交易量
- [ ] 可切换总量/现货/合约
- [ ] 可勾选交易所显示/隐藏
- [ ] 事件流可展示
- [ ] 可按类型筛选事件
- [ ] 事件点击可查看摘要

## 4. 页面结构

```
┌─────────────────────────────────────────────────────────┐
│  Header: Exchange Monitor                    [刷新按钮] │
├─────────────────────────────────────────────────────────┤
│  筛选器栏:                                              │
│  [总量 ●] [现货 ○] [合约 ○]    交易所: [☑Binance ☑OKX...] │
│  事件类型: [全部 ▼]              时间范围: [7天 ▼]        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                    主图表区域                            │
│           (BTC 价格 + 交易量多曲线)                      │
│                                                         │
│    ↑ 价格/交易量                                        │
│    │    ┌───┐           ┌───┐                          │
│    │    │   │  ┌───┐     │   │                          │
│    │ ───┘   └──┘   └─────   └──→ 时间                   │
│    │    ● 事件标注点                                   │
│                                                         │
├─────────────────────────────────────────────────────────┤
│  事件流区域:                                            │
│  ┌─────────────────────────────────────────────────────┐│
│  │ 🟢 2026-03-17 14:00 | 上币 | Binance 上线 XXX       ││
│  │ 🔵 2026-03-17 10:00 | 活动 | Bybit 合约返现活动      ││
│  │ 🟠 2026-03-16 18:00 | 公告 | OKX 升级风控系统        ││
│  └─────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────┘
```

### 4.1 页面模块

| 模块 | 说明 |
|------|------|
| Header | 标题 + 刷新按钮 |
| 筛选器栏 | 业务线切换、交易所勾选、事件类型筛选、时间范围 |
| 图表区 | ECharts 主图表（价格 + 交易量） |
| 事件流 | 事件列表，可滚动 |
| 事件详情 | 弹窗形式展示事件摘要 |

## 5. 图表交互

### 5.1 主图表

| 交互 | 行为 |
|------|------|
| 鼠标悬停 | 显示当前点数据 tooltip（价格、时间、各交易所交易量） |
| 鼠标拖拽 | 时间轴拖拽查看 |
| 滚轮缩放 | 放大/缩小时间范围 |
| 点击事件点 | 弹出事件详情 |

### 5.2 图例交互

| 交互 | 行为 |
|------|------|
| 点击图例 | 切换该曲线显示/隐藏 |
| 图例拖拽 | 排序曲线上下位置 |

### 5.3 事件标注

- 事件点以圆点形式标注在图表时间轴上
- 不同事件类型对应不同颜色：
  - 🔴 公告
  - 🟢 上币
  - 🔵 活动
  - 🟠 产品更新
  - 🟣 社媒热点
  - 🟡 行业新闻

---

## 6. 筛选器

### 6.1 业务线切换

| 选项 | 说明 |
|------|------|
| 总量 | 现货 + 合约交易量之和 |
| 现货 | 仅现货交易量 |
| 合约 | 仅合约交易量（永续 + 交割） |

### 6.2 交易所勾选

默认全选，可单独取消勾选：
- ☑ Binance
- ☑ OKX
- ☑ Bybit
- ☑ Bitget
- ☑ Hyperliquid

### 6.3 事件类型筛选

| 类型 | 筛选值 |
|------|--------|
| 全部 | (空) |
| 公告 | announcement |
| 活动 | campaign |
| 上币 | listing |
| 产品更新 | product |
| 社媒热点 | social |
| 行业新闻 | news |

### 6.4 时间范围

| 选项 | 范围 |
|------|------|
| 24 小时 | T-24h ~ T |
| 7 天 | T-7d ~ T |
| 30 天 | T-30d ~ T |

## 8. 非目标范围

### 8.1 MVP 不包含

| 范围 | 说明 |
|------|------|
| 实时推送 | MVP 为网页查看，无通知 |
| 交易功能 | 不涉及下单、充值等 |
| 链上数据 | 不包含 on-chain 数据 |
| 历史回溯 | MVP 仅支持 30 天 |
| 社交登录 | MVP 无需登录 |
| 移动端 | 仅支持桌面端 |
| API 开放 | MVP 不提供 API |

### 8.2 明确不做

- ❌ 交易下单
- ❌ 钱包地址查询
- ❌ KYC/认证
- ❌ 广告投放
- ❌ 社区论坛
