# Page Interactions v0.1

## 1. 页面布局
### 顶部
- 页面标题
- 时间范围切换
- 交易所选择器
- 市场类型切换

### 中部
- 主图：BTC price + exchange volume

### 下部
- 事件流列表
- 事件详情卡片

## 2. 主图交互
- 鼠标 hover 显示 tooltip
- tooltip 内容：
  - 时间
  - BTC 价格
  - 当前显示的交易所 volume
- 图例可点击隐藏/显示某条线

## 3. 筛选器交互
### 交易所
支持多选：
- Binance
- OKX
- Bybit
- Bitget
- Hyperliquid

### 市场类型
单选：
- total
- spot
- futures

### 时间范围
单选：
- 7d
- 30d
- 90d

## 4. 事件流交互
- 默认展示当前图表时间范围内事件
- 可按事件类型筛选
- 点击事件后，右侧或弹层显示：
  - 标题
  - 发布时间
  - 来源
  - 摘要
  - 外链

## 5. 联动规则
- 切换时间范围后，主图和事件流一起更新
- 切换市场类型后，只更新 volume 数据
- 点击主图事件点后，滚动定位到对应事件卡片

## 新增交互补充 v0.2

### 1. 主图事件点
- 主图时间轴上展示事件点 marker
- marker 按事件类型可区分样式
- 鼠标 hover 显示事件标题、时间、类型
- 点击 marker 后，联动下方事件流高亮对应事件
- 后续可扩展为弹出详情卡片

### 2. 交易所颜色规范
- Binance：黄色
- OKX：深蓝
- Bybit：橘色
- Bitget：天蓝
- Hyperliquid：绿色

### 3. 事件流筛选
- 事件流顶部展示事件类型筛选项
- 点击某类后，仅显示对应事件
- 支持“全部”选项恢复
